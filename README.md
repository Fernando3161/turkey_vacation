# Turkey Loop Travel Photography

This repository contains the source and published assets for a day-based travel photography website about a loop through Turkey.

The site will be organized around travel days. Each day can contain a short story, location context, and optimized web photos grouped by theme. The project is intended to publish through GitHub Pages, with optimized images stored under `public/photos/`.

## Project Structure

- `assets/css/` - future stylesheet files.
- `assets/js/` - future browser JavaScript files.
- `public/data/` - future structured data for days and content.
- `public/photos/` - optimized photos that are safe to publish.
- `pictures/` - local high-resolution photo workflow folders.
- `scripts/` - local utility scripts for photo preparation.
- `.github/workflows/` - future GitHub Actions workflows.

## Current Phase

Phase 3.1 creates the repository structure and project documentation only. It does not add frontend behavior, route data, OSRM scripts, or map generation.
